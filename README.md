# FIB — Federal Investigation Bureau (Totally Real!)
A satirical single-page parody website where users can report suspects, browse a hilariously suspicious database, and enjoy a high-tech (but extremely questionable) “surveillance” experience — all powered by modern front-end web technologies.


Built as a creative and humorous project, this SPA showcases:

- A responsive layout with dynamic page switching
- Fake forms and database interaction (localStorage-based)
- Custom design and branding inspired by fictional government agencies
- A playful and ironic tone that parodies over-the-top surveillance culture
